# CaPI — Capacitación en Protección de Propiedad Intelectual y Transferencia de Tecnología

CaPI es una capacitación para grupos de investigación. Cada grupo documenta **su propio proyecto** con **DiDe**,
un método de documentación con herramientas de calidad aplicadas a innovación.

Documentar con DiDe sirve para dos cosas:

1. **Ver qué partes del trabajo son protegibles y cuáles no.** Con eso el grupo puede decidir qué patentar, qué
   guardar y qué divulgar, y no gasta energía buscando patentes donde no hay nada que proteger.
2. **Dejar el sistema modular, extensible, transferible, certificable, escalable y eficiente**, por la forma misma
   en que se documenta.

## La ruta DiDe

| # | Herramienta | Pregunta que responde |
|---|---|---|
| 1 | Concepto | ¿Qué es la idea y por qué importa? |
| 2 | A3 | ¿Se entiende el proyecto entero en una sola hoja? |
| 3 | Diagrama de procesos | ¿En qué orden se hace cada parte, con qué entradas y salidas? |
| 4 | Ishikawa 6M | ¿Qué hay que controlar para que el resultado se repita? |
| 5 | WBS constructible | ¿Qué hay que hacer en cada parte, y cómo se hace? |
| 6 | Diccionario de WBS | ¿Cómo se llama cada parte, y qué significa? |
| 7 | BIM tecnológico | ¿Qué documentación necesita cada tipo de usuario? |

## Qué hay en este repositorio

| Carpeta | Contenido |
|---|---|
| `Plantillas/` | Modelos en blanco para completar: encuesta de Concepto, A3, guía de WBS constructible y Diccionario de WBS. |
| `Ejemplos/SincLE/` | Un ejemplo resuelto: el A3 de **SincLE**, un sistema que sincroniza un láser y un espectrómetro LIBS. Está en HTML (se edita en el navegador y se imprime en A3), Markdown y PDF. |

Las plantillas usan ejemplos de **otro** proyecto a propósito: muestran el nivel de detalle esperado sin que se
pueda copiar la respuesta.

## Cómo usar las plantillas

1. Empezá por la encuesta de Concepto (`Plantillas/CaPI-Universal_01-Encuesta-Concepto.md`). Respondé cada
   pregunta mirando el ejemplo.
2. Destilá las respuestas en el A3 (`Plantillas/CaPI-Universal_02-Plantilla-A3.md`). Mirá el A3 de SincLE para
   ver cómo queda.
3. Seguí con la guía de WBS y el Diccionario.

Lo que produce cada grupo con estas plantillas es **suyo y confidencial**: no lo subas a un repositorio público
hasta saber qué partes conviene proteger.
